SocialLens 工作窗口

扩展会在这个窗口里打开平台页面来取数，用完的页面几分钟后自动关闭，这个说明页会一直留着，好让窗口不必每次重新弹出。

可以把它缩小、挪到屏幕一角或另一块屏幕，位置会记住。

不要最小化或让别的窗口把它整个盖住：有些平台靠页面滚动加载下一页，看不见的页面不会加载。任务需要时会把最小化的窗口还原，但不会抢走焦点。

关掉这个窗口也没关系，下次需要时会重新打开。

SocialLens work window

The extension opens platform pages here to fetch data. Finished pages close after a few minutes; this note stays so the window does not have to pop up again for every task.

Do shrink it, move it to a corner or to another screen; its position is remembered.

Don't minimize it or let another window cover it completely: some platforms load the next page only while the page is visible. A task restores a minimized window without taking focus.

Closing it is fine; it reopens the next time it is needed.
