# 参与贡献 / Contributing

中文 | [English](#english)

欢迎提 issue 和 PR。提交之前请先读完下面的「贡献授权」，提交即表示你同意它。

## 开发

```bash
cd backend && uv run pytest        # 后端测试
cd extension && pnpm typecheck && pnpm test
```

新增平台、录制样本的方式见 README 的「开发」一节。录制样本含账号信息，不要提交到仓库。
