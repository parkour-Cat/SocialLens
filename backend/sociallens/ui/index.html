其他客户端的配置：{"command": "uv", "args": ["run", "--project", "<repo>/backend", "sociallens-mcp"], "env": {"SOCIALLENS_URL": "http://127.0.0.1:17800"}}
约定 Swagger ↗openapi.json ↗

后端只监听本机 ，没有鉴权，程序直接调。

成功响应是 {success: true, data, cursor?, task_id?}，失败是 {success: false, error: {code, message}}。列表类的 data 是 {items, total, kind?}，翻页把顶层 cursor 原样传回去；cursor 绑定一个浏览器标签页，闲置几分钟后过期（cursor_expired），从第一页重来即可。

错误码：not_logged_in 未登录，extension_offline 扩展没连上，captcha_required 站点要求验证，队列暂停，rate_limited 被限流，cursor_expired 游标过期，timeout 页面没在时限内给出数据，unsupported 该平台没有这个动作，not_found 对象不存在。
